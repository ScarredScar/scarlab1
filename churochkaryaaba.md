# Ответы на контрольные вопросы

## Вопрос 1

Инструкция `syscall` — это аппаратный механизм процессора x86-64, который выполняет контролируемый переход из пользовательского режима (Ring 3) в режим ядра (Ring 0).

При её выполнении происходит:
1. Сохранение контекста — адрес возврата в `RCX`, флаги в `R11`.
2. Загрузка адреса обработчика из MSR-регистра `IA32_LSTAR`.
3. Смена уровня привилегий с CPL=3 (Ring 3) на CPL=0 (Ring 0).
4. Переключение стека на стек ядра (`RSP` → `TSS.RSP0`).
5. Маскирование прерываний.
6. Передача управления обработчику, который по номеру в `RAX` определяет нужный системный вызов.

Кольца защиты — аппаратные уровни привилегий: Ring 0 (ядро) и Ring 3 (пользователь). Пользовательская программа не может напрямую обращаться к устройствам или памяти ядра — только через `syscall`.

## Вопрос 2

Назначение регистров при `sys_write`:

| Регистр | Значение | Назначение |
|---------|----------|------------|
| `RAX` | 1 | Номер системного вызова (`sys_write`) |
| `RDI` | 1 | Дескриптор файла (1 = stdout) |
| `RSI` | адрес `message` | Указатель на буфер с данными |
| `RDX` | `message_len` | Количество байт для записи |

После заполнения регистров инструкция `syscall` передаёт управление ядру, которое выполняет запись и возвращает число записанных байт в `RAX`.

## Вопрос 3

Причина — в уровне абстракции. Ассемблерная программа не использует `libc`, не выделяет кучу, не читает конфиги — делает ровно `write` и `exit`.

Python перед `write` выполняет сотни вызовов:
- Подсистема памяти: `brk`, `mmap`, `munmap` — выделение виртуальных страниц.
- Подсистема файлов: `openat`, `fstat`, `read`, `close` — загрузка `libc`, `libpython`, модулей стандартной библиотеки.
- Подсистема процессов и сигналов: `rt_sigaction`, `prctl`, `arch_prctl`, `getrandom`.
- Вывод: `newfstatat(1, ...)` — проверка, является ли stdout терминалом, затем `write(1, ...)`.
- Завершение: `exit_group(0)`.

Каждое действие — отдельный переход Ring 3 → Ring 0. Поэтому у Python сотни записей в `strace`, а у ассемблерной программы — три.
